
# offline-mobil-asistan
Çiftçiler için internet erişimi olmadan çalışabilen mobil tarla ve ürün takip asistanı.

## Kullanılan Teknolojiler ve Altyapı
- **Framework:** React Native
- **Çalıştırma Ortamı / Araç:** Expo Go
- **Geliştirme Ortamı (IDE):** Visual Studio Code (VS Code)
- **Programlama Dili:** JavaScript
